# Week 11 Mini Project - Student Information System

## Project Title
Student Information System (OOP-Based)

## System Description
A simple menu-driven student information system built using object-oriented programming. The system stores student records in a text file and supports adding, viewing, and searching students.

## Features
- Add Student
- View Students
- Search Student
- Exit Program
- File handling for persistent storage
- Input validation and basic exception handling

## How to Run
1. Open a terminal in the `oop-python-course/week11_mini_project` folder.
2. Run `python main.py`.

## Sample Output
```

4 Exit
```
